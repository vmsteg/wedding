# Свадебное агентство

> Современный одностраничный сайт для свадебного агентства. 

---
## Адрес рабочего проекта

Проект размещён на платформе GitHub Pages и доступен для просмотра по ссылке:

[https://vmsteg.github.io/wedding/]

##  О проекте

Данный проект представляет собой **полноценный клиентский веб-интерфейс** для свадебного агентства, работающий полностью на стороне пользователя без использования серверной инфраструктуры. Сайт создан с учётом современных требований к веб-дизайну: адаптивность, интерактивность, удобство навигации и эмоциональная вовлечённость пользователя.

### Основная идея

Предоставить свадебному агентству инструмент для:
- презентации своих услуг и портфолио;
- сбора заявок от потенциальных клиентов;
- формирования положительного имиджа и доверия.

---

## Функциональные возможности

### Для посетителя сайта

| Функция | Описание |
|---------|----------|
| Главный экран | Акцентное изображение, название агентства, слоган и кнопка призыва к действию |
| Об агентстве | Информация о компании: год основания, количество проектов, преимущества |
| Услуги | Карточки с описанием всех предоставляемых услуг |
| Портфолио | Галерея фотографий с возможностью фильтрации по категориям и увеличенным просмотром |
| Отзывы | Карточки с мнениями реальных клиентов |
| Контакты | Контактная информация и форма обратной связи |



---

## Технологический стек

| Технология | Назначение |
|------------|------------|
| **HTML5** | Семантическая разметка страницы |
| **CSS3** | Стилизация, Flexbox, Grid, адаптивный дизайн, медиа-запросы |
| **JavaScript (vanilla JS)** | Клиентская логика, фильтрация портфолио, модальное окно, валидация формы |
| **Font Awesome** | Библиотека иконок для визуального оформления |
| **Google Fonts** | Шрифты Playfair Display (заголовки) и Inter (основной текст) |
| **Git** | Система контроля версий |
| **GitHub Pages** | Хостинг для публикации сайта |
